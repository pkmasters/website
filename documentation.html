Documentation

Welcome to the documentation page! Here you'll find detailed information about how I set up my website and the services I host.

Website Setup

I am using a Cloudflare domain from their registrar, which is a paid service per year. My website is hosted on GitHub Pages, where I created a pages repository and linked my domain to it. Additionally, I created a DNS record on Cloudflare to point to the GitHub Pages IP address. The website is built using simple HTML and CSS files.

Accessing Services with Twingate VPN

To access all of my services over the internet securely, I use Twingate VPN. This allows me to access local resources without exposing any ports.

Services For Public Access

For services that I host that integrate with the Internet, it all exposed using Cloudflare ZTNA.

With Zero Trust, I can "safely" expose my public services via a Cloudflare Tunnel. That way there is no exposed ports on my WAN IP, and users can access those services freely. For the most part, Cloudflare has been reliable, and downtime is very minimal and is usally on my side of infra.

Hosting Services

I have a home server based on an HP Elitedesk 800 G4, running Proxmox VE. I have multiple VMs and LXCs running to service my needs; Network Management, DNS, Automation, Monitoring, App Testing, the like.

Services Hosted in Proxmox VE

  • Helpdesk: I am using Zammad for ticket management.
  • Monitoring Service: Uptime Kuma for monitoring locally available service uptime. Gatus for monitoring externally available service uptime
  • DNS: Technitium DNS in a 2x cluster managing all internal DNS records and advertising/malicious domains. Forwaded to an internal AD to retain internal domain access.
  • Password Management: Vaultwarden, works with official Bitwarden applications.
  • Remote Management: ControlR, for all my servers.
  • Game Servers: Crafty, hosting a Minecraft server. (now migrated to my cloud server)

Crafty and Public Access Setup

For my Minecraft server (Crafty), I use standard DNS records and port forwarding to allow players to join my Minecraft Server.

This typically involves adding public DNS records that point to the server IP on the Minecraft server port. This is done through SRV records.
